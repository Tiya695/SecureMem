Terms & Conditions

Please review the system policy and security rules governing SecureMem multi-agent memory storage.

1. Introduction

Welcome to SecureMem. SecureMem provides an encrypted recall and active security policy layer for multi-agent LLM systems. By integrating our SDK or utilizing our Threat Console, you agree to these Terms and Conditions, which are designed to ensure memory integrity, hardware-grade safety, and policy alignment across your software agents.

2. Memory Safety & Encryption Policy

To maintain memory safety across autonomous entities, the following rules apply:

  • Hardware-Grade Encryption: All memory shards stored via SecureMem are subject to secure AES-GCM encryption. Users are responsible for preserving access credentials.
  • Prompt Injection Defense: SecureMem actively scans all incoming read/write shards for indirect prompt injections or behavioral poisoning attacks. System trust scores will fluctuate based on the volume of flagged activities.
  • Sanitized Recall: Memory reads that violate pre-configured system rules will be automatically redacted, classified, and logged inside the Audit Logs.

3. Permitted Use & Agent Management

You agree not to use SecureMem to store memory states representing:

  • Malicious code, spyware, or payloads engineered to exploit autonomous agent workflows.
  • Personally Identifiable Information (PII) in unencrypted format that violates global compliance regulations.
  • Deceptive instructions aiming to artificially trigger system overrides or override standard sandbox safety limits.

4. System Administration & Review Queue

Systems Administrators have access to the Admin Review Queue. In the event of flagged threat scores, administrators have the unilateral right to override memory blocks, quarantine suspect agents, or adjust system trust thresholds to secure the network core.

5. Disclaimer of Warranties

SecureMem is provided "as is". While we strive for a 99.8% clean recall rate and low latency policies, we do not warrant that memory recall will be entirely free from latency or that system classifiers will detect 100% of all emergent agent prompt injections.
